<b>CIFS Datei-Explorer</b> adds your network shares – NAS, Windows PC, Samba server – directly to the Android Files app. No extra file manager needed: shares show up as a storage location in "Files" and in every file picker.

<b>Features</b>
<ul>
<li>SMB 2/3 (smbj, jCIFS-NG) and SMB 1, plus FTP, FTPS and SFTP</li>
<li>Integration via the Storage Access Framework (SAF) – works with every app that opens or saves files</li>
<li>Stream videos and music directly from your NAS, including seeking</li>
<li>Discover devices in your local network</li>
<li>Multiple connections, reorderable via drag &amp; drop</li>
<li>Encrypted export/import of connections</li>
<li>Modern Material 3 design with dynamic colors (Material You) and dark mode</li>
<li>Fully translated into German, more languages included</li>
</ul>

<b>Notes</b>
<ul>
<li>The app itself is not a file manager – manage your files in the Files app or any other SAF-capable app.</li>
<li>Apps that only support local storage may not work.</li>
</ul>
